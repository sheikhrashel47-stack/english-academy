# Emerald Study House — Style Refinement Log

The current visual refinement retires the former **Learner’s Atlas** identity. Course navigation and progression use a CEFR ribbon and factual lesson sequence rather than maps, route pins, travel markers, or terracotta accents.

Typography now inherits a single bilingual system: **Manrope** for English interface content and **Noto Sans Bengali** for Bangla content. Weight, scale, spacing, and muted/emerald contrast establish hierarchy; serif display type is not used in learning content, questions, or course cards.

The material system uses neutral surfaces, restrained borders, mint support states, and emerald as the single action/navigation color. Practice and course pages follow the same system as the dashboard and tools hub.

Vocabulary now reads as a searchable **study library**, and progress as a factual **learning ledger** with a CEFR-oriented current-level summary. Neither surface uses route maps, pins, landmarks, or travel language.
