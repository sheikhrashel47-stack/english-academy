# English Academy — Master Visual Direction

> **Design amendment:** The attached Master Product Design Specification supersedes the previous terracotta cartographic direction. All new and revised UI must follow this selected premium-academic system.

## Selected direction: Emerald Study House

### Design Movement

**Premium Light Academic** with contemporary educational-productivity cues. The product should feel like a trusted personal study environment: calm, mature, precise and encouraging—never cartoonish, game-like or visually noisy.

### Core Principles

1. **The learning action leads.** Every screen exposes one obvious next step before supplementary metrics or tools.
2. **Quiet academic confidence.** Spacious neutral canvases, factual progress, carefully weighted type and restrained elevation replace gamified spectacle.
3. **Guided complexity.** English Academy can grow into a broad learning system, but navigation, groups and progressive disclosure prevent cognitive overload.
4. **Bilingual without dilution.** English target content is primary; Bangla explanation is legible, supportive and secondary.

### Color Philosophy

The signature **Academy Emerald `#146B4D`** represents deliberate forward learning, selected navigation and primary action. It is supported by a quiet `#F6F8F5` neutral canvas, white learning surfaces and soft mint states. Semantic colours are reserved for actual success, warning, error and informational feedback. Bright rainbow accents, purple gradients and terracotta route markers are intentionally excluded.

### Layout Paradigm

Desktop uses a grounded three-zone study workspace: collapsible left navigation, a focused central learning canvas and an optional narrow insight rail only when it has useful current information. Mobile is a single-purpose sequence with exactly five bottom-nav destinations and bottom sheets for secondary work. Lesson, question and writing screens switch into distraction-reduced Focus Mode.

### Signature Elements

1. **CEFR level ribbon:** a calm, segmented mastery indicator that connects the learner’s current level to the full path from Pre-A1 to C2.
2. **Learning ledger:** a slim factual record used for mission, review and history—never a decorative streak game.
3. **Emerald focus line:** a short left-edge or top-edge signal that identifies the active learning task without turning every card into a coloured panel.

### Interaction Philosophy

Feedback is immediate, calm and instructive. The learner can always return safely, retry without shame and resume interrupted work. A feature that is planned but not implemented names the limitation clearly and offers an available related learning action rather than becoming a dead end.

### Animation

Use transform and opacity only: 120–180ms for press/hover feedback and 180–240ms for panels and route transitions. Primary button press scales to `0.97`. Progress changes are responsive, not theatrical. All nonessential motion is removed for `prefers-reduced-motion`.

### Typography System

Use **Manrope** for English UI and **Noto Sans Bengali** for Bangla, with a system sans-serif fallback. The hierarchy is sans-serif throughout: bold Display/H1 for page intent, clear H2/H3 for learning chunks, and generously led body text for bilingual explanations. Bangla text must use comfortable line-height and never be reduced below readable body size to make room for English.

### Brand Essence

**English Academy is the connected, premium learning workspace where Bangla-speaking learners steadily move from first words to fluent use.**

**Personality:** calm, capable, scholarly.

### Brand Voice

Headlines make a learning purpose concrete; CTAs name the next task; microcopy is supportive and factual.

> “আজকের ছোট পরিকল্পনা, তোমার পরের কথোপকথনের প্রস্তুতি।”

> “এবার মিলল না—চলো, কারণটি দেখি।”

### Wordmark and logo

Retain a distinct book-and-compass mark only if it is refined in Academy Emerald and works as a small app icon. The wordmark uses a compact, custom-feeling bilingual lockup rather than default browser text. The mark must remain recognisable without text and appear clearly in the sidebar, mobile header and favicon.

### Style Decisions

- Surfaces use subtle borders and small-to-medium radii; no excessive pill or cartoon treatment.
- Cards are variants of one system, not unrelated boxed modules.
- The primary button is emerald; user progress and insight must come from real persisted data.
- Full light, dark and focus themes use intentional semantic tokens rather than inverted colours.
- Images only support a learning task and never compete with readable content or the primary CTA.
- Before each UI decision, ask: **“Does this reinforce the calm, connected learning workspace—or dilute it?”**
- The former **Learner’s Atlas** identity is retired: no atlas tagline, map illustration, travel-marker motif or terracotta route colour appears in revised screens.
- The **CEFR ribbon** is the primary learning-journey motif on dashboard and course views; future levels are factual and understated.
- Manrope and Noto Sans Bengali remain the only interface typefaces. Serif display typography is not used in questions, course cards, headings or learning content.
- CTA and status labels remain factual and instructional; planned tools explicitly identify their availability and point learners to a working alternative.
- **Color discipline:** Academy Emerald `#146B4D` and soft mint are the only brand accents; copper, maroon, orange, purple and decorative warm stamps are excluded except for true semantic warning/error states.
- **Bilingual hierarchy:** English target content leads at display scale, while Bangla guides and reassures in a calmer secondary line; equal-weight mixed-language display headlines are avoided unless the learning task requires both.
- **Signature motif rule:** Every major learning screen carries one understated Academy motif—an Emerald focus line, learning-ledger row or CEFR/progress ribbon—so the workspace is recognisably English Academy rather than a generic education UI.
